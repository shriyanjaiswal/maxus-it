# SEO, QA and Launch Checklist

## Content and trust
- [ ] Company history, founding members, locations and contact details verified.
- [ ] All service capabilities approved.
- [ ] Portfolio projects and screenshots approved for publication.
- [ ] Client permissions confirmed for names, logos and case studies.
- [ ] Privacy policy reflects actual form, analytics and data handling.

## Technical SEO
- [ ] Unique title and meta description for every route.
- [ ] Canonical URLs use the confirmed domain.
- [ ] Sitemap generated and accessible.
- [ ] robots.txt reviewed.
- [ ] Organization structured data uses verified details.
- [ ] Service structured data used only where appropriate.
- [ ] Open Graph title, description and image configured.
- [ ] No broken internal links or placeholder routes.
- [ ] Custom 404 page works.

## Forms and contact
- [ ] Phone link tested.
- [ ] Email link tested.
- [ ] WhatsApp number confirmed and link tested.
- [ ] Email form sends a real test submission.
- [ ] Validation, loading, success and failure states tested.
- [ ] Spam protection configured.
- [ ] No secret keys exposed in frontend bundle.

## Responsive and accessibility
- [ ] Test 1440, 1024, 768, 390 and 360 px widths.
- [ ] No horizontal overflow.
- [ ] Keyboard navigation and visible focus tested.
- [ ] Form fields have accessible labels.
- [ ] Color contrast checked.
- [ ] Reduced-motion preference respected.
- [ ] Images have appropriate alt text.

## Performance and deployment
- [ ] Images optimized and correctly sized.
- [ ] Below-fold images lazy-loaded.
- [ ] Hero image loading priority reviewed.
- [ ] Production build succeeds.
- [ ] No console errors.
- [ ] Domain DNS and HTTPS checked.
- [ ] SPA fallback configured for direct route loads.
- [ ] Analytics and Search Console configured if required.

# MAXUS IT SERVICES Website AI Build Package

This package contains the website brief, structured content data, UI direction, desktop/mobile wireframes, master AI coding prompt and launch checklist.

## Folder structure
- `01_brand_assets/` — supplied company logo.
- `02_content_data/` — company, services, portfolio, sitemap and content brief.
- `03_ui_design/` — design tokens, desktop/mobile specifications and SVG wireframes.
- `04_ai_prompts/` — master prompt for your AI coding tool.
- `05_seo_and_launch/` — SEO, QA and launch checklist.
- `06_development_reference/` — route/component planning reference.

## How to use
1. Unzip this package.
2. Add the complete brand kit and real approved portfolio assets to `01_brand_assets/` and an `assets/portfolio/` folder.
3. Replace `NEEDS_CLIENT_DOMAIN` with the actual domain when known.
4. Confirm the phone/WhatsApp number, email recipient, history, founding members and locations.
5. Replace the example project in `portfolio.json` with actual approved projects. Do not publish the example placeholder.
6. Open `04_ai_prompts/master-ai-development-prompt.md`.
7. Give the entire extracted package to your AI coding tool along with the prompt.
8. Ask the AI to inspect all files first, then build the website in the existing repository.
9. Configure a real form provider before launch.
10. Run the checklist in `05_seo_and_launch/seo-qa-launch-checklist.md`.

## Important
The SVG wireframes are layout references, not finished visual designs. The JSON files are starter content models. The logo included is the supplied logo; the rest of the complete brand kit and portfolio files should be added if they are stored separately.

Never publish unverified claims, fake case studies, invented metrics or unauthorized client materials.

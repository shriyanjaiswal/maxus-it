# Desktop UI Specification

## Canvas and layout
- Reference viewport: 1440 × 1000 px.
- Content max-width: 1280 px, centered.
- Horizontal page padding: 32 px.
- Header: approximately 84 px tall; logo left, navigation center/right, high-contrast CTA.
- Main typeface: Manrope or Plus Jakarta Sans for headings; Inter for body.
- Visual style: premium enterprise technology, white content surfaces, navy hero and restrained lime accent.

## Hero
- Desktop hero is a two-column layout: copy approximately 52%, artwork approximately 48%.
- Eyebrow: “SMART TECHNOLOGY. REAL BUSINESS VALUE.”
- H1: “Technology That Moves Your Business Forward.”
- Body: “From professional websites and custom software to ERP, billing and inventory solutions, MAXUS IT SERVICES helps businesses simplify operations and build for the future.”
- Primary CTA: “Discuss Your Project”
- Secondary CTA: “Explore Our Work”
- Hero artwork: globe/orbit inspired by the actual logo, floating software panels, blue glow and subtle lime highlight. No text baked into the image.
- Hero background: deep navy; keep sufficient negative space behind text.

## Below the fold
1. Company introduction / verified company history.
2. Eight-service grid (4 columns on wide desktop, 2 on tablet).
3. Featured portfolio (3 cards across, or 4 where content permits).
4. Business solutions feature with approved dashboard screenshot.
5. Four-step process: Understand → Plan → Implement → Support.
6. Final CTA band.
7. Multi-column footer.

## Component behavior
- Buttons have hover/focus states and clear action labels.
- Cards use subtle borders, no exaggerated shadows.
- Portfolio filters update visible projects and remain keyboard accessible.
- Use consistent card image aspect ratios.
- Sticky header optional; do not let it obscure anchor links.
